Readers who print a runbook get something usable at a desk.

## What changes on paper

| Element    | Print behaviour                                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------ |
| `chrome`   | Header, sidebar, on-this-page, feedback and pager are dropped; content takes the full page width |
| `colour`   | Forced to plain black on white — code blocks invert to save toner                                |
| `links`    | External URLs are printed after the link text, so a paper copy stays followable                  |
| `breaks`   | Headings never end a page; code blocks and tables never split mid-row                            |
| `details`  | Collapsible sections print expanded — paper has no disclosure triangle                           |
| `diagrams` | Print their source, since Mermaid renders in the browser                                         |

## Print this page

<PrintButton text="Open print preview" />

Nothing is generated on a server — it is the same HTML with a print stylesheet at
`src/styles/base/_print.css`. Your browser's own shortcut (⌘P, or Ctrl+P on Windows) does
exactly the same thing, which is why the button hides itself when JavaScript is off rather
than sitting there dead.

## Page setup

<CodeBlock
  language="css"
  filename="src/styles/base/_print.css"
  code={'@page {\n  margin: 18mm 16mm 20mm;\n  size: A4;\n}\n\n@media print {\n  .prose a[href^="http"]::after { content: " (" attr(href) ")"; }\n  :is(h1, h2, h3) { break-after: avoid; }\n  pre, table, figure { break-inside: avoid; }\n  details::details-content { content-visibility: visible; }\n}'}
