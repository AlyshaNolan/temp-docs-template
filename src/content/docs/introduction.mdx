## What it is

A file-based docs site, distributed as a GitHub template rather than a package. You copy the
repository once and own the result: write Markdown in `src/content/docs/`, set a `group` in
frontmatter, and get a site with search, dark mode, an on-page table of contents, a print
layout and generated reference pages. Nothing updates itself, and there is no theme to keep
in step.

It is built for [CloudCannon](https://cloudcannon.com/), so every component ships the
configuration that makes it editable on the page — but the build is plain Astro and runs
anywhere.

Everything on this site — the sidebar you're using, the ⌘K overlay, the code tabs below — is
the template itself. There is no separate demo.

## Who it's for

Product teams shipping something that needs docs for three audiences at once:

- **Developers** integrating your API — reference pages, copyable samples in their language.
- **Operators** configuring your product — option tables, defaults, deprecation notes.
- **End users** learning the app — task guides with screenshots and callouts.

## What's included

| Area         | Ships with                                                                |
| ------------ | ------------------------------------------------------------------------- |
| `navigation` | Grouped sidebar, breadcrumbs, prev/next, mobile drawer                    |
| `discovery`  | Full-text search built with the site, keyboard-first overlay, sitemap     |
| `content`    | Callouts, tabbed code, annotated code, tables, definition lists, diagrams |
| `lifecycle`  | Changelog page, feedback votes, print layout, 404 with search             |
