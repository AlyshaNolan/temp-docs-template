## site

<ParamList
  params={[
    { name: "wordmark", type: "string", required: true, description: "Shown in the header, page titles and OG metadata." },
    { name: "markLetter", type: "string", description: "One character rendered in an accent tile beside the wordmark. Ignored when `logoSource` is set." },
    { name: "logoSource", type: "string", description: "Path to an SVG or PNG, replacing the mark and wordmark. Pair with `logoAlternateSource` to swap per colour mode." },

    { name: "repositoryUrl", type: "string", description: "The site's source repository. `src/utils/repository.ts` derives the per-page \"Edit this page\" link from it; a `/tree/<branch>` suffix names the branch edit links target, defaulting to `main`. Empty hides the link." },
  ]}

## Reading config in a component

`docsSite.json` is a plain JSON import, so any component can read it directly — there is no
config loader to learn.

<CodeTabs
  tabs={[
    { label: "Astro", language: "astro", code: "---\nimport docsSite from \"@data/docsSite.json\";\n---\n\n<p>{docsSite.wordmark} {docsSite.version}</p>" },
