## redirects.json

<ParamList
  params={[
    {
      "name": "routes",
      "type": "{ from, to, status }[]",
      "description": "Old URLs and where they go now. `from` is a path on this site; `to` is a path or a full URL; `status` is `\"301\"` (permanent) or `\"302\"` (temporary). Add one whenever a page is renamed or moved, so shared links keep working."
    }
  ]}
/>

<Alert
  variant="warning"
  title="Redirects only work on CloudCannon hosting"
  text="`npm run build` turns these into CloudCannon's routing file, so they take effect on the next build of a CloudCannon-hosted site. Another host ignores them — recreate them in that host's own redirect config."
/>

## Reading config in a component

Each file in `src/data/` is a plain JSON import, so any component can read it directly — there is no
config loader to learn.

<CodeTabs
  tabs={[
    {
      "label": "Astro",
      "language": "astro",
