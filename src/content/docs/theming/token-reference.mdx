## Everything else

Spacing, radius, type, line height, borders, shadows, z-layers and motion are all
`src/styles/variables/*`. Print `npm run lint:css-vars -- --list` for the full set — it reads
them out of the files, so it can't go stale.

<Alert
  variant="danger"
  title="An unresolved token fails silently"
  text="`var(--colour-text)` is invalid at computed-value time, so the declaration just inherits — no error in review, the build, or usually the page. `npm run check` fails on it, which is the only reason you find out."
/>
