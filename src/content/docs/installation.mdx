## Prerequisites

- Node 22.12 or newer
- npm. The committed lockfile is npm's, so pnpm and yarn aren't supported
- A GitHub account. There is no installer and no npm package: the template is a repository you
  copy and then own.

## Copy the template

Two routes, both ending with a repository of your own.

### From GitHub

Open [Use this template](https://github.com/AlyshaNolan/temp-docs-template/generate) on the
repository, name your copy, then clone it and install:

<CodeBlock
  language="bash"
  filename="terminal"
  code={"git clone https://github.com/your-org/acme-docs.git\ncd acme-docs\nnpm ci"}
/>

<Alert
  variant="note"
  title="npm ci, not npm install"
  text="`npm ci` installs the exact versions in the lockfile. A bare `npm install` can rewrite it in a way that breaks the Linux build in CI."
/>

### From CloudCannon

Use the **Deploy to CloudCannon** button at the top of the repository's README. CloudCannon
copies the repository for you, runs the first build, and opens the site with visual editing already
wired up — every component on this site carries the CloudCannon configuration that makes it
editable on the page.

<Alert
  variant="warning"
  title="CloudCannon is a paid product"
  text="Building and hosting a site on CloudCannon requires a paid plan — see [CloudCannon pricing](https://cloudcannon.com/pricing/). The template itself is MIT licensed and builds anywhere — see “Do I have to use CloudCannon?” below."
/>

## Run the dev server

<CodeBlock
  language="bash"
  filename="terminal"
  code={"npm run dev\n\n  → docs ready at http://localhost:4321\n  → watching src/content/docs for changes"}
/>

<Alert
  variant="tip"
  title="Port already in use?"
  text="Pass `--port 5000`, or set `server.port` in `astro.config.mjs`."
/>

## Add your first page

Create an `.mdx` file anywhere under `src/content/docs/`. The path becomes the URL.

<Alert
  variant="warning"
  title="The extension must be .mdx"
  text="Only `.mdx` files are loaded. A `.md` file in `src/content/docs/` is skipped without an error, so the page simply never appears. MDX is Markdown plus components — write it exactly as you would Markdown."
/>

<CodeBlock
  language="mdx"
  filename="src/content/docs/webhooks.mdx"
  code={"---\ntitle: Webhooks\ndescription: Receive events as they happen.\ngroup: Guides\norder: 2\n---\n\nSubscribe to events and we'll POST them to your endpoint."}
/>

## Deploy

`npm run build` emits a static `dist/` — search index included — that any static host will
serve. No server runtime, no database. CloudCannon runs the same command; so does Netlify,
Vercel or a GitHub Actions job that pushes to Pages. [Going live](/going-live/) walks through
hosting it and replacing the template's placeholders.
