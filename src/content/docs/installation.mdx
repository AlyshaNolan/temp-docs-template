## Prerequisites

- Node 22.12 or newer
- Any package manager — npm, pnpm or yarn
- A GitHub account. There is no installer and no npm package: the template is a repository you
  copy and then own.

## Copy the template

Two routes, both ending with a repository of your own.

### From GitHub

Open [Use this template](https://github.com/AlyshaNolan/temp-docs-template/generate) on the
repository, name your copy, then clone it and install:

```bash title="terminal"
git clone https://github.com/your-org/acme-docs.git
cd acme-docs
npm ci
```

<Alert
  variant="note"
  title="npm ci, not npm install"
  text="`npm ci` installs the exact versions in the lockfile. A bare `npm install` can rewrite it in a way that breaks the Linux build in CI."
/>

### From CloudCannon

Use the **Deploy to CloudCannon** button on the template's listing. CloudCannon forks the
repository for you, runs the first build, and opens the site with visual editing already
wired up — every component on this site carries the CloudCannon configuration that makes it
editable on the page.

<Alert
  variant="warning"
  title="CloudCannon is a paid product"
  text="Building and hosting a site on CloudCannon requires a paid plan. The template itself is MIT licensed and builds anywhere — see “Do I have to use CloudCannon?” below."
/>

## Run the dev server

```bash title="terminal"
npm run dev

  → docs ready at http://localhost:4321
  → watching src/content/docs for changes
```

<Alert
  variant="tip"
  title="Port already in use?"
  text="Pass `--port 5000`, or set `server.port` in `astro.config.mjs`."
/>

## Add your first page

Create a Markdown file anywhere under `src/content/docs/`. The path becomes the URL.

```mdx title="src/content/docs/webhooks.mdx"
---
title: Webhooks
description: Receive events as they happen.
group: Guides
order: 2
---

Subscribe to events and we'll POST them to your endpoint.
```

## Deploy

`npm run build` emits a static `dist/` — search index included — that any static host will
serve. No server runtime, no database. CloudCannon runs the same command; so does Netlify,
Vercel or a GitHub Actions job that pushes to Pages. See [Configuration](/configuration/) for
the settings a deploy usually needs.
